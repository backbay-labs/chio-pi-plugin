# PR 3 independent review and remediation

Reviewed base: `0658112131019571123c5b171d48c472faa22032`.

Scope: the complete branch source and contracts, prior review evidence, native Pi
1.0.2 and Durable 1.0.2 integration, original-operation/ACK provenance, governed
model and child execution, recipe and guest confinement, private filesystem state,
CLI diagnostics, package construction, cold consumers and hosted workflows.
Review and fixes were performed in an isolated worktree. The original checkouts,
normal Pi profile, unrelated containers and prior evidence were preserved.

## Findings

No P0 defect was established. One P1 and six P2 defect groups were reproduced or
confirmed against the source. All seven groups have changes and regressions.

| Priority | Defect and consequence | Remediation and verification |
| --- | --- | --- |
| P1 | Malformed private prepared, transport and session JSON exposes credential-bearing source fragments through JSON parser errors. | Withhold source bytes at all three readers. Regression assertions check the error text with synthetic credential bytes. |
| P2 | An interrupted atomic publication leaves a temporary, or a temporary hardlink to an already-published original, which permanently prevents parent/Durable restart. | Under exclusive native owner custody, discard only validated temporary files, preserve published records, and refuse symlinks, external hardlinks and unsafe modes. Restart tests retain the same effect and delivery identities. |
| P2 | The 4096-record read limit makes retained originals and diagnostic state unavailable after a store reaches its lifetime threshold. | Apply capacity at fresh admission. Keep historical records readable, refuse new originals before publication, and retain explicit original recovery and native-validated approval resumes. Regressions load 4097 valid records. |
| P2 | Parent mapping serialization is process-local, so a second process can overwrite delivery provenance without owning the gateway. | Require the actual native gateway owner before every parent mutation and Durable attachment/write. Reject aliasing a live provenance directory under another store identity. Tests prove a foreign owner cannot mutate records or remove a writer's temporary. |
| P2 | Durable observer close releases writer custody while an admitted tool still runs. Session closure also need not settle the separate ACK observer. | Retain custody until admitted callbacks and private writes settle, without blocking the caller from reaching Session cancellation. Drain the ACK observer before rebinding a closed backend. Cover active execution, unsafe interruption, observer reattachment and an ACK paused across Session closure. |
| P2 | npm's redaction of UUID path components defeats exact host-path replacement and permits a falsely clean consumer graph containing an absolute local archive path. | Normalize the selected graph dependency structurally; require exactly one replacement; reject all remaining absolute file resolutions. Retain graph equality checks before normalization and exercise redacted and unrelated absolute paths. |
| P2 | Hosted CI lacks bubblewrap and two tests assume a prepared Linux recipe runtime. The prior run fails 19 tests and never reaches consumer qualification. | Install the launcher prerequisite in CI and release workflows. Make the publication-fault test's qualified-runtime requirement explicit and construct the missing-library fixture independently of ambient pins. Confined Linux qualification remains separate. |

Additional hardening explicitly denies ptrace, process_vm_readv/writev and
pidfd_getfd in both recipe seccomp architectures. This is not a demonstrated
sandbox escape: upstream bubblewrap 0.8.0 applies the filter to its PID 1 reaper
as well as its final command. The source comments now reflect that contract.
Source: <https://raw.githubusercontent.com/containers/bubblewrap/v0.8.0/bubblewrap.c>
(`do_init`, `seccomp_programs_apply`).
