# Acknowledgement confirmation loss

Failing predecessor evidence. The actual host received a verified result, but
the acknowledgement confirmation response was dropped. The guest discarded
that result and reported uncertainty. A subsequent host using the same authority
dispatched another write. The independent resource observer records two writes
and the replacement bytes. This reopens I07 for this artifact.

The repair moves acknowledgement to the trusted launcher after native host
history contains the full verified outcome. New candidate qualification remains
required; these failures are never counted as acceptance.
